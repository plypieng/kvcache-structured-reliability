# Dataset Sources

## tinystories

- Dataset: roneneldan/TinyStories
- Description: Synthetic short stories for training and evaluating small language models.
- Dataset URL: https://huggingface.co/datasets/roneneldan/TinyStories
- Paper: TinyStories: How Small Can Language Models Be and Still Speak Coherent English?
- arXiv: https://arxiv.org/abs/2305.07759
- PDF: https://arxiv.org/pdf/2305.07759

## structeval

- Dataset: TIGER-Lab/StructEval
- Description: Structured-output benchmark covering JSON, XML, YAML, CSV, TOML and renderable formats.
- Dataset URL: https://huggingface.co/datasets/TIGER-Lab/StructEval
- Paper: StructEval: Benchmarking LLMs' Capabilities to Generate Structural Outputs
- arXiv: https://arxiv.org/abs/2505.20139
- PDF: https://arxiv.org/pdf/2505.20139

## synthetic_structured

- Dataset: mdonigian/synthetic-structured-output-dataset
- Description: Synthetic structured-output/function-calling style dataset.
- Dataset URL: https://huggingface.co/datasets/mdonigian/synthetic-structured-output-dataset
- Paper: no corresponding paper found; dataset card only

## sob

- Dataset: interfaze-ai/sob
- Description: Structured Output Benchmark for schema compliance and value accuracy.
- Dataset URL: https://huggingface.co/datasets/interfaze-ai/sob
- Paper: The Structured Output Benchmark: A Multi-Source Benchmark for Evaluating Structured Output Quality in Large Language Models
- arXiv: https://arxiv.org/abs/2604.25359
- PDF: https://arxiv.org/pdf/2604.25359
